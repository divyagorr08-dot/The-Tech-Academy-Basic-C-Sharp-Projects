This repository contains the C# projects I completed while learning .NET Framework, ASP.NET MVC, Entity Framework, and general C# programming fundamentals. These projects demonstrate my understanding of OOP, MVC architecture, Code‑First workflows, LINQ, SQL databases, and real‑world application design.

## Car Insurance (ASP.NET MVC)

This project is a MVC web application that mimics a car insurance website. It takes user's input on policy information and calculates a quote based on business logic. There is also an admin page that allows staff to view all of the quotes that have been issued.

## Student Database – Code First (Console App)

This project is a console application built using Entity Framework 6 with a Code‑First workflow. It automatically generates a SQL Server database based on C# classes and inserts a sample student record when the program runs. The project demonstrates how Code‑First modeling, DbContext configuration, and basic data persistence work together in a lightweight .NET application.
